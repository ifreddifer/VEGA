# VEGA

**Vertente Específica Gerada Aleatoriamente**

Assistente pessoal local em desenvolvimento.

## Sobre

A VEGA é um projeto pessoal de desenvolvimento de uma assistente capaz de conversar naturalmente, possuir memória seletiva, utilizar ferramentas e interagir com o computador.

O projeto tem como objetivo explorar conceitos de:

- Inteligência Artificial
- Programação
- Processamento de linguagem natural
- Reconhecimento e síntese de voz
- Automação
- Bancos de dados
- Desenvolvimento de software
